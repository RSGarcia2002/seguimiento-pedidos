# Referencia visual

Fuente: https://tataaccessories.org/es, consultada el 29/10/2026.
Se inspeccionaron el HTML, las variables de los esquemas y custom.css del sitio.

| Elemento | Referencia verificada |
| --- | --- |
| Fuente de cuerpo y títulos | Jost, pesos 400 y 700 |
| Fondo | #FFFFFF |
| Superficie secundaria | #F3F3F3 |
| Texto principal | #121212 |
| Acento del segundo esquema | #9E252D |
| Fondo oscuro del tercer esquema | #242833 |

Aplicación: tipografía local mediante @fontsource/jost, colores centralizados,
superficies planas, bordes discretos, espacios amplios y esquinas de 4px.
Los tonos secundarios y la composición son adaptaciones para seguimiento de pedidos.
La marca textual del encabezado es una aproximación tipográfica; no es el logotipo original.
El diseño se ampliará con las vistas funcionales, sin inventar pedidos o indicadores.
